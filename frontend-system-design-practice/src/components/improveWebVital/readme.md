## 04. How would you improve Web Vitals (LCP, CLS, INP)?
**একজন Senior Frontend Engineer হিসেবে, পারফরম্যান্স অপ্টিমাইজেশন আমাদের ডিএনএ-তে থাকা উচিত। Web Vitals শুধু গুগল র‍্যাঙ্কিংয়ের জন্য নয়, বরং এটি ইউজার এক্সপেরিয়েন্সের একটি মেট্রিক।**

##### চলুন LCP, CLS, এবং INP নিয়ে গভীরে আলোচনা করি।

### 1. Largest Contentful Paint (LCP)
Concept: এটি মূলত Loading Performance পরিমাপ করে। পেজের সবচেয়ে বড় এলিমেন্ট (যেমন: হিরো ইমেজ, ভিডিও বা বড় টেক্সট ব্লক) রেন্ডার হতে কত সময় নিচ্ছে, সেটিই LCP।

**How it works:**
ব্রাউজার যখন পেজ লোড করে, সে প্রতিনিয়ত মনিটর করে কোন এলিমেন্টটি সবচেয়ে বড়। যখনই নতুন কোনো বড় এলিমেন্ট স্ক্রিনে আসে, LCP আপডেট হয় যতক্ষণ না ইউজার ইন্টারঅ্যাক্ট করছে।

- Good LCP: < 2.5 seconds.

**Why we need it:**
ইউজার যখন কোনো সাইটে আসে, সে সবার আগে বড় কন্টেন্টটি দেখতে চায়। এটি লোড হতে দেরি হলে ইউজার মনে করে সাইটটি স্লো বা কাজ করছে না।

**How to Improve (Real-life Examples):**
- Critical Path CSS: ইনলাইন সিএসএস ব্যবহার করে রেন্ডার ব্লকিং সিএসএস কমানো।
- Image Optimization: next/image (Next.js) ব্যবহার করা বা fetchpriority="high" অ্যাট্রিবিউট হিরো ইমেজে যোগ করা।
- CDN: ব্যবহারকারী যেখানে আছে, সেখান থেকে কন্টেন্ট সার্ভ করা।
- Example: ধরুন একটি ই-কমার্স সাইটের ব্যানার ইমেজ অনেক বড়। আপনি যদি সেটি priority ট্যাগ দিয়ে লোড করেন, তবে ব্রাউজার অন্য সবকিছুর আগে সেটি নামিয়ে আনবে।

### 2. Cumulative Layout Shift (CLS)
Concept: এটি Visual Stability পরিমাপ করে। পেজ লোড হওয়ার সময় হুট করে কন্টেন্ট নড়ে যাওয়া (Layout shift) ইউজারের জন্য বিরক্তির কারণ।

**How it works:**
ব্রাউজার ক্যালকুলেট করে কতটুকু কন্টেন্ট আনস্পেক্টেডলি মুভ করেছে।
    - CLS = Impact\ Fraction \times Distance\ Fraction
    - Good CLS: < 0.1.

**Why we need it:**
ধরুন আপনি একটি 'Cancel' বাটনে ক্লিক করতে যাচ্ছেন, কিন্তু হুট করে উপরে একটি অ্যাড লোড হওয়ায় বাটনটি নিচে নেমে গেল এবং আপনি ভুল করে 'Buy Now' বাটনে ক্লিক করে ফেললেন। এই বাজে অভিজ্ঞতা রোধ করতেই CLS।

**How to Improve (Real-life Examples):**
- Set Dimensions: ইমেজ বা ভিডিওর জন্য সবসময় width এবং height নির্দিষ্ট করে দিন।
- Ad Slot Reservation: অ্যাড লোড হওয়ার আগে সেখানে একটি প্লেসহোল্ডার বা স্কেলেটন লোড করে রাখুন।
- Avoid Dynamic Content insertion: পেজের ওপরের দিকে হুট করে কোনো এলিমেন্ট ইনসার্ট করবেন না।
- Example: ইমেজের জন্য aspect-ratio সিএসএস প্রোপার্টি ব্যবহার করা যাতে ব্রাউজার আগেই জায়গাটা ব্লক করে রাখে।

### 3. Interaction to Next Paint (INP)
Concept: এটি Responsiveness পরিমাপ করে। ইউজার যখন কোনো ক্লিক বা কি-প্রেস করে, তখন ব্রাউজার কতটা দ্রুত সেই ফিডব্যাক দিতে পারে, সেটিই INP। (এটি FID-কে রিপ্লেস করেছে)।

**How it works:**
INP পুরো ভিজিট চলাকালীন সবচেয়ে লম্বা ল্যাটেন্সি (Delay) হিসেব করে। এটি তিনটি পর্যায় নিয়ে গঠিত:
 1. Input Delay: ইভেন্ট শুরু হতে যতটুকু দেরি হয়।
 2. Processing Time: জাভাস্ক্রিপ্ট কোড এক্সিকিউট হতে যে সময় লাগে।
 3. Presentation Delay: ব্রাউজার নতুন ফ্রেম রেন্ডার করতে যে সময় নেয়।

- Good INP: < 200 milliseconds.

**Why we need it:**
ইউজার যখন একটি মেনু বাটনে ক্লিক করে, সে চায় সাথে সাথে মেনুটা ওপেন হোক। যদি ক্লিক করার ১ সেকেন্ড পর মেনু খোলে, তবে ইউজার ফ্রাস্ট্রেটেড হয়ে পড়ে।

**How to Improve (Real-life Examples):**
- Break up Long Tasks: ভারী জাভাস্ক্রিপ্ট কাজগুলোকে setTimeout বা requestIdleCallback ব্যবহার করে ছোট ছোট ভাগে ভাগ করা।

- Optimize Event Handlers: ক্লিক ইভেন্টের ভেতর অপ্রয়োজনীয় ভারী ক্যালকুলেশন না রাখা।

- Web Workers: ব্যাকগ্রাউন্ড থ্রেডে ক্যালকুলেশন পাঠানো যাতে মেইন থ্রেড ফ্রি থাকে।

- Example: একটি বড় লিস্ট ফিল্টার করার সময় জাস্ট লিস্ট আপডেট না করে একটি লোডার দেখানো এবং ফিল্টারিং কাজটিকে ছোট ছোট চাঙ্কে (Chunk) ভাগ করা।
